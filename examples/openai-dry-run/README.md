# Fabricated Responses API outputs

These complete layouts are plumbing fixtures, not model outputs or recommended compositions. Only the offline mock transport uses them; they are never included in live prompts.

They exercise repeated assets, stable uids, movement, scaling, rotation, both local-axis flips, adding f4/f5, removing f5, and layer order. Both portraits deliberately use the same normalized coordinates; this is not an assessment of visual quality.
